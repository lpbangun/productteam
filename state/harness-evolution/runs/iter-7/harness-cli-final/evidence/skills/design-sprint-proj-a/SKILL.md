# /design-sprint — Frame a product problem into an executable plan

## Purpose

Turn a vague request or product problem into a bounded improvement plan.

## Produces

- problem framing
- target users
- product direction
- implementation scope
- milestones
- risks
- validation plan
- expected impact

## Invoke

```sh
bin/productteam skill design-sprint <repo-or-client> [out-dir]
```

Writes `design-sprint.md` under `out-dir`.

## Rules

- Smallest scope that can move a frozen benchmark
- Client vision is a constraint
- Escalate architecture / security / autonomy per CONSTITUTION.md
