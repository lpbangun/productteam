# TUI polish lessons

1. **Freeze before app edits worked.** The locked HTML became 29 independently scored dimensions; the Freeze Critic accepted them; `FREEZE-SHA.txt` prevented scope weakening. All seven frozen inputs still hash clean after convergence.

2. **Functional zeros precede 8.x polish.** The original five-iteration run improved identity and streaming but stopped with five zero-score seams. The owner-authorized extension first shipped structured ask/confirm, then evidence/Command/toast/card semantics, then splash, before spending the final slice on proof gaps.

3. **A green Textual pilot is not real terminal proof.** Native tests missed slash-focus theft, slow provider drain, ANSI-split headers, and empty-artifact/live-cap behavior. Six real executable PTY rows now cover routing, interrupt, role argv, confirm, resize, and the silent-work-to-speech transition.

4. **Polling must bind to the process-owned session.** The live strip reads the active TUI `session-{pid}` and retargets from `ARTIFACT=`. Reusing `/workers` glob-latest could display stale activity while idle.

5. **Thinking and speech are separate state machines.** Running `workers.tsv` rows belong in `#activity`; first artifact bytes open one role rail. Completion metadata must not replay the artifact body.

6. **Streaming needs a drain loop.** One read before `wait()` lost slow output. Preserve the byte offset, drain while alive, final-drain after exit, and keep draining through interrupt teardown.

7. **Timer redraws can hide observable tails.** Skip nonessential chrome paints while real CLI output is queued; bound exit behind `_cli_busy` so the final Command rows reach the terminal.

8. **ANSI-normalized deltas are transport-correct, not weaker needles.** Textual inserts CSI between styled glyphs and can paint stale-width frames during SIGWINCH. Strip control sequences, isolate the invocation/reflow delta, then assert the same glyphs, absences, score slot, cap, and restored frame.

9. **Screen chrome creates false absence matches.** Role chips always contain all four labels. Empty-artifact proof must forbid speaking rail openers (`│ ◆`, `│ ◇`, `│ ▸`, `│ ◉`), not role names globally.

10. **Capture prompt composition before stdout.** A hold provider records the real `-p` argv before emitting bytes. That proves `prompt_export` without printing control data into the artifact and accidentally opening speech.

11. **Filesystem recency needs an explicit key.** `status --json` has no timestamp. Home recency now uses the latest valid numeric `iter-N/scores.json` mtime, numeric iteration fallback, and stable client tie-break; cwd mapping can pin one slot without disordering the remainder.

12. **Freeze semantics outrank a debate typo.** After typing `@Builder`, compact chrome must show `@Builder`, not the idle default `@Principal`. Correcting the proof preserved Q15 rather than weakening it.

13. **Interrupt assertions must respect chronology.** Waiting only for the first toast allowed the force-exit Ctrl+C to race the failed-card paint. The PTY row now observes reap/preserve/failed-card first, then verifies the second Ctrl+C exits 130.

14. **One Writer prevented overwrite churn.** Each non-trivial slice had one Worker; the Principal ran full gates; independent Critics scored. No duplicate writer was launched even when a task exceeded the prior 30-minute warning.

15. **Iteration limits are governance, not acceptance shortcuts.** The original five-iteration FAIL remained honest. The owner explicitly authorized an extension without changing D01–D29. The loop stopped at iter-9, the first independent all-pass; iter-10 was not started.
