## 3. Registry and argv wiring

Palette is derived from live `productteam help --json`. Do not hardcode a second verb list. If JSON and `lib/commands.sh` disagree, the CLI is right.

**Invocation rule:** every CLI function the TUI runs goes through an argv array to `bin/productteam`. No `shell=True`, no `eval`, no concatenated command strings.

### 3a. Chat-supported — execute

From live inspect (18):
`/help` `/status` `/agents` `/runtime` `/org` `/memory` `/report` `/bench` `/score` `/run` `/judge` `/checks` `/harness-checks` `/skill` `/gh` `/onboarding` `/splash` `/smoke`

Pass through args (`/report harness-cli`, `/score harness-cli --iter 1`). Missing required args: print registry `usage`, do not guess. Stream real stdout/stderr into the transcript with markdown-lite. Update chips from `state/.cli/runs/session-*/workers.tsv`.

### 3b. Chat-only — session local, same semantics as `lib/repl.sh`

`/provider [name]` — session-only `CONSULT_PROVIDER` via `runtime_have` / `runtime_cycle`
`/workers` — render the file-backed strip
`/clear` — clear transcript (not durable state)
`/export` — write markdown under `${STATE_ROOT}/sessions/` and print the path
`/exit` `/quit` — leave the TUI, restore termios

### 3c. Chat-unsupported — refuse, do not spawn

Show mute reason + `use the CLI: {usage}` from registry `chat_reason`.

From live inspect (14):
`/gate` `/inspect` `/workspace` `/direction` `/escalation` `/role` `/open` `/baseline` `/style` `/card` `/pool` `/project-memory` `/run-loop` `/chat`

Nested `productteam chat` is refused. After `tui` is registered it is also `chat_supported=0` and must refuse if typed as `/tui`.

### 3d. Bare text

Real provider turn, same ownership as `productteam chat`:
- `activity_start` / spinner fields / completion card
- process-group kill+reap on first Ctrl+C
- preserve partial artifact bytes
- mark worker failed
- second Ctrl+C exits 130 and restores termios

Reuse `lib/repl.sh` / `lib/activity.sh` / `lib/provider.sh`. Do not reimplement a provider supervisor in Python. Do not mock the live provider path.
