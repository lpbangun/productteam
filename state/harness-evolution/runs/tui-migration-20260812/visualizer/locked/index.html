ProductTeam · locked cockpit

This is the visual contract for lib/tui/. One design, shown through its states. Presentation client of bin/productteam and plain files. Not a daemon, not a second state authority, not a replacement for productteam chat.

All product questions are locked. No alternatives on this page. Goal-loop workers match these frames.

Boot splash · R7

Once, then the cockpit. Composer and footer stay visible. Live-boot subtitle names the currently glowing head.

Open · Q1 Q3 R8

Three recent scored sessions for this directory. No activity strip while idle. Home rows are not a picker. Default target Principal.

Prompt sent · thinking stays in activity

Your prompt is a gray-railed You turn. Silent workers appear only in activity, from workers.tsv. Header middle head pulses.

Speaking · markdown-lite · completion card

A colored turn starts only when the role emits text. Markdown-lite lives inside that turn. Done is a card on the turn, not a new message.

Ask-back · Q6

The question is a real Principal turn. Options dock above the composer. Never a modal over the transcript.

Slash · R2

Palette docks immediately above the composer. Input stays the filter. Run, refuse, and usage are mute Command rails — never a Builder color.

Evidence · R3

Long file lists do not drown chat. Summary stays a Command turn. The file list is a bordered labelled panel.

Confirm write · R4

Only real registry verbs that write. Dock above the composer. Cancel spawns nothing.

Toasts · R5

Fail and interrupt are toasts, not extra transcript lines. Session verbs stay mute.

40-col · Q5

Explicit compact mode, not wrapping. Drop heads and directory. One activity line plus +N. Composer stays.

Empty states

Honest first screens when there is no provider or no scored engagement. Not the status dump.
