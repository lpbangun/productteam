1. **correctness** — `npm test` (build + `tests/rendered-html.test.mjs`) passes; three labels and protection order intact in `app/ReadinessKit.tsx` / `DESIGN.md`.

4. **developer-experience** — Scripts in `package.json` (`test`, `lint`, `test:browser`) remain accurate and runnable.
5. **product-clarity** — Audiences (contributor vs quality lead) and “simulation / not employment tooling” framing stay unmistakable.
6. **simplicity** — Prefer smallest diffs; no new services, auth, or persistence.
7. **safety-honesty** — Visible UI guardrails match `AGENTS.md` non-negotiables (no automatic punitive / disciplinary / hiring / firing / **pay** / **promotion** / personnel decisions); fictional labels remain visible.
